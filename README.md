# TutorIA Platform
Versión actual: 0.9.0

TutorIA Platform es la base tecnológica para la planeación educativa asistida por inteligencia artificial, consulta normativa, capacitación, seguimiento y supervisión en guarderías.

## Alcance Incluido en v0.9.0
- React + Vite.
- Firebase Authentication.
- Firestore.
- Control de acceso.
- Gestión de sesión.
- Layout base.
- Rutas protegidas.
- Servicios reutilizables.
- Integración base con n8n.
- Estructura documental y de activos.

## Alcance Excluido
- Planeación Semanal v2.
- Generación pedagógica definitiva por IA.
- Flujo productivo de revisión y aprobación.
- PDF institucional final.
- Chat normativo productivo.
- Indicadores del piloto.

## Estructura del Repositorio

- `tutoria-app/`: Aplicación frontend principal.
- `tutoria-docs/`: Documentación del proyecto.
- `tutoria-assets/`: Recursos gráficos y multimedia.
- `tutoria-ai-knowledge/`: Base de conocimientos y prompts de IA.
- `tutoria-scripts/`: Scripts de automatización y utilidad.
- `tutoria-backups/`: Respaldos y copias de seguridad.
