## [0.9.0] - 2026-07-23

### Added
- Arquitectura base de TutorIA Platform.
- Autenticación con Firebase.
- Rutas protegidas y control de sesión.
- Layout principal reutilizable.
- Servicios base de Firebase y n8n.
- Estructura de documentación, activos, conocimiento IA, scripts y respaldos.
- Archivo `.env.example` sin credenciales.
- Repositorio saneado y preparado para desarrollo productivo.

### Removed
- Componentes específicos del MVP anterior.
- Planeaciones pedagógicas heredadas.
- Chat normativo del prototipo.
- PDF institucional del MVP.
- Seeds y lógica específica de GuarderíasIMSS.

### Security
- Archivo `.env` eliminado del seguimiento de Git.
- Reglas de exclusión corregidas.
- Commit inicial saneado antes de publicación.
