# TutorIA Visual DNA

**Version:** 1.0 (Phase B3.4 Polish)
**Status:** Approved by ARB
**Scope:** Defines the visual rules for the Pedagogical Character System.

---

## 1. Geometría (The Mathematics of Closeness)

- **Curvas:** Prohibido el uso de esquinas perfectas de 90° en rostros o cuerpos orgánicos. Todo debe basarse en *Squircles* (superelipses) para transmitir suavidad y accesibilidad.
- **Radios:**
  - Caras/Visores del Companion: `rx="45"` sobre un bounding box de `150x120`.
  - Personas: Abstracciones curvas sin ángulos afilados.
- **Volumen:** Uso de Flat Design con sombras sutiles. Prohibido el 3D realista. Las sombras deben ser *DropShadows* difusos (ej. `stdDeviation="12"`, opacity `15%`).

## 2. Color (The Palette of Trust)

- **Turquoise (`#00B4D8` a `#48CAE4`):** El color primario del conocimiento, tecnología e IA. Usado para el Aura, indicadores de proceso, destellos y ojos de estados activos.
- **Deep Blue (`#023E8A` a `#03045E`):** Estabilidad, liderazgo, la institución. Usado para la base estructural del Companion, trajes formales (Tere), sombras profundas.
- **Orange (`#F77F00` a `#FFB703`):** Calidez, celebración, empatía, humanidad. Usado para las mejillas, acentos de bufandas, chispas de éxito, corazones o manos cálidas.
- **Neutros Cálidos:** Para las *Personas*, la piel debe usar gradientes suaves desde `#FDF8F5` hasta tonos crema/durazno, evitando grises robóticos.

## 3. Expresividad (The System of Eyes)

Los ojos son la ventana de la intención pedagógica.
- **Greeting / Success:** Arcos curvos amplios hacia arriba `^ ^`. Transmiten alegría.
- **Thinking:** Asimetría controlada. Un ojo neutro o chico, el otro levantado `_ ^`. Transmite proceso o sorpresa curiosa.
- **Waiting / Idle:** Líneas rectas planas `- -` o muy levemente curvas. Transmite reposo, sin interrumpir.
- **Helping / Empathy:** Curvas apuntando sutilmente hacia abajo `\ /` o curvas cerradas. Transmite atención y compresión profunda.
- **Observing / Listening:** Círculos grandes `O O` y aros concéntricos. Transmite recepción activa.

## 4. Personajes (The Family)

Todo personaje debe sentirse como parte de TutorIA. Si se ponen uno al lado del otro, deben compartir grosor de líneas, opacidad de sombras y falta de narices/bocas hiperrealistas.

1. **Lumina (Companion):** El núcleo pedagógico. No es un robot de chat genérico. Es un busto flotante elegante con antena integrada y rostro/pantalla brillante. Su aura dicta su nivel de procesamiento cognitivo.
2. **Anita (Docente Maternal):** Formas suaves, redondas. Bufandas naranjas/turquesas. Postura relajada pero atenta. Refleja paciencia infinita.
3. **Tere (Directora):** Líneas rectas, hombreras y cuello de blazer. Lentes a medio marco (autoridad e intelecto). Refleja liderazgo, orden y protección.
4. **Ceci (Supervisora):** Dinamismo asimétrico. Inclinada siempre hacia el frente. Refleja energía, seguimiento y acompañamiento continuo.

## 5. Reglas Inmutables (What Must Never Change)

- **NUNCA usar avatares de stock (fotografías).**
- **NUNCA agregar narices, labios realistas o pupilas complejas.** La abstracción es clave para evitar el "uncanny valley".
- **NUNCA usar animaciones bruscas o frenéticas.** Todo debe respirar.
- **NUNCA dibujar al Companion con extremidades (piernas) tipo humano.** Es una entidad flotante.

## 6. Evolución Permitida (What Can Grow)

- Se pueden añadir nuevos props sutiles (ej. un libro, una estrella flotando, una pizarra).
- Nuevos colores de Aura para nuevos estados cognitivos (ej. verde para éxito de servidor, morado oscuro para errores del sistema).
- Nuevos cortes de cabello o acentos de ropa en futuras expansiones de Personas (ej. Docentes de Preescolar, Psicólogos), siempre respetando la geometría *Squircle* plana.
