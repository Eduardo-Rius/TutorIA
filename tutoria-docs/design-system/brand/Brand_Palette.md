# Brand Palette (CANDIDATE)

Esta paleta es semántica y se deriva de la extracción de activos maestros. Todo valor es `PROPOSED` y `CANDIDATE`.

## Brand Colors
- `brandPrimary` (Navy `#003c58`)
- `brandSecondary` (Teal `#0ca994`)
- `brandAccent` (Orange `#ff9e02`)
- `brandHighlight`: Teal translúcido (derivado candidato).

## Text Colors
- `textPrimary`: Navy muy oscuro (`#002233` - derivado) para máxima legibilidad.
- `textSecondary`: Gris azulado (`#4a5568` - derivado) para subtítulos.
- `textMuted`: Gris claro (`#a0aec0` - derivado) para placeholders.
- `textInverse`: Blanco puro (`#ffffff`) para botones primarios.
- `textLink`: Teal profundo (`#0b8876` - derivado) para contraste WCAG AA.

## Surface Colors
- `surfacePrimary`: Blanco puro (`#ffffff`).
- `surfaceSecondary`: Gris/Navy ultraclaro (`#f7f9fb` - derivado) para fondos de pantalla.
- `surfaceElevated`: Blanco con sombra.
- `surfaceTinted`: Fondo Teal ultraclaro (`#e6f6f4` - derivado) para cards destacadas.
- `surfaceInverse`: Navy oscuro (`#003c58`) para tooltips o dark sidebars.

## Border Colors
- `borderSubtle`: Gris muy claro (`#e2e8f0` - derivado).
- `borderDefault`: Gris medio (`#cbd5e1` - derivado).
- `borderStrong`: Navy translúcido.
- `borderFocus`: Teal con glow (`ring-teal-500`).

## Feedback Colors
- `success`: Teal/Verde esmeralda (derivado).
- `warning`: Brand Orange (`#ff9e02`).
- `danger`: Red institucional (Candidato a definir, ej. `#e53e3e`).
- `information`: Azul claro (derivado).

## Interaction Colors
- `actionPrimary`: Brand Teal (`#0ca994`).
- `actionPrimaryHover`: Teal oscurecido (`#0b8876` - derivado).
- `actionSecondary`: Outline Navy o Outline Teal.
- `actionDisabled`: Gris apagado (`#e2e8f0`).

## Escalas Derivadas (Teal - Ejemplo Matemático Candidato)
- `teal-50`: `#f0fbf9`
- `teal-100`: `#ccf3ec`
- `teal-500`: `#0ca994` (Base)
- `teal-700`: `#097e6e`
- `teal-900`: `#054a41`
