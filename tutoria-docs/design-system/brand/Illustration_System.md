# Illustration System (CANDIDATE)

El sistema de ilustración de TutorIA se basa en los elementos presentes en el escudo/sello y el logotipo: Robot, Sol, Libro, Niños, Corazón y Planeta.

## Estilo Visual
- **Flat 2D Evolucionado:** Colores sólidos (Teal, Orange, Navy) con sutiles sombras planas para separar profundidad. 
- **Proporciones:** Geométricas, redondeadas, amigables pero no caricaturizadas en exceso.
- **Nivel de detalle:** Minimalista. Sin trazos gruesos de contorno (sin strokes negros).

## Elementos y Simbolismo
- **Robot TutorIA:** Tecnología inteligente y asistencia pedagógica. (Ver Mascot Guidelines).
- **Sol (Orange):** Optimismo, nuevo día, iluminación, infancia.
- **Libro (Teal/White):** Pedagogía, normativa, registro académico.
- **Corazón:** Empatía, cuidado infantil, calidez humana.
- **Planeta:** Inclusión, amplitud, diversidad de centros.

## Usos Permitidos
- **Empty States:** Un robot sosteniendo un libro vacío para invitar a crear una planeación.
- **Onboarding:** Ilustraciones hero (composición sol + niños + robot) para dar la bienvenida.
- **Fondos de Login:** Composiciones vectoriales expansivas.
- **Diversidad:** Si se ilustran personas, deben ser inclusivas en tonos de piel y género.

## Usos Prohibidos
- **NO mezclar estilos:** No usar renders 3D junto a ilustraciones flat.
- **NO deformar:** Mantener las proporciones originales del robot.
- **NO saturar:** Una pantalla operativa (ej. tabla de planeaciones) no debe llevar ilustraciones. Reservar para estados vacíos o onboarding.
- **NO usar imágenes stock genéricas** si entran en conflicto con la paleta de la marca.
