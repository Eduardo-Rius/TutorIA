# Digital Product Identity
*(PROVISIONAL: Sujeto a revisión visual final del ARB)*

## Uso en Pantallas y App

- **Master Transparent:** Para áreas amplias de identidad, on-boarding o login.
- **Imagotype Transparent:** Versión preferida para headers verticales o paneles compactos.
- **Logotype Transparent:** Versión preferida para navbars o menús horizontales.
- **Isotype Robot:** Diseñado para representar al asistente virtual, estados vacíos y avatares.
