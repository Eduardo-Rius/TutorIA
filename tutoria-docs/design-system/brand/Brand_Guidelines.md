# Brand Guidelines
*(PROVISIONAL: Sujeto a revisión visual final del ARB)*

## Logo Usage System (CANDIDATE)
Las directrices provisionales para la aplicación de activos marcarios:

- **Login / Onboarding:** `TutorIA_Master_Transparent.png` o `TutorIA_Imagotype_Transparent.png` centrado o hero, área de seguridad de 24px mínimo.
- **Navbar Web:** `TutorIA_Logotype_Transparent.png`. Área libre vertical mínima de 8px.
- **Favicon / Avatar Móvil:** `TutorIA_Isotype_Robot`. (Versión optimizada pendiente).
- **Fondos Claros (Blanco/Gris muy claro):** Variantes Color o Variantes Transparentes directamente.
- **Fondos Oscuros (Navy):** ⚠️ Requieren versión Inversa Blanca sólida (pendiente de aprobación, o aplicar filter CSS/máscara).
- **Relación de Aspecto:** NUNCA distorsionar. Siempre usar `object-fit: contain` o mantener proporción bloqueada.

## Recomendaciones de Uso Temático
- **Master:** Material institucional, promocional y portadas de documentos.
- **Imagotype:** Identidad compacta para software u hojas membretadas.
- **Logotype:** Encabezados de informes y barras de navegación del portal.
- **Isotype Robot:** Inteligencia Artificial, favicon y estado del sistema.
- **Education Seal:** Diplomas de fin de curso, avales, y certificaciones.

## Política Master / Derivados
### MASTER ASSETS
Los archivos dentro de `tutoria-docs/design-system/brand/logos/` son los originales canónicos. Nunca modificarlos.

Los archivos en `tutoria-app/src/assets/brand/` son derivados autorizados (App Eligible). Toda optimización generará un nuevo export.
