# Typography (CANDIDATE)

El sistema tipográfico de TutorIA debe equilibrar legibilidad prolongada (para lectura de normativa) y modernidad institucional.

## Filosofía Tipográfica
El logotipo utiliza una tipografía geométrica sans-serif moderna, pero forzarla en todo el cuerpo de texto puede fatigar al lector en documentos densos.

## Propuestas Candidatas (System Stacks & Open Fonts)

### 1. Inter (Recomendada)
- **Función:** Font universal para UI y Body.
- **Justificación:** Extraordinaria legibilidad en pantallas de baja resolución, excelente altura de la 'x', neutral y moderna. Soporte nativo de Google Fonts y exportación perfecta a PDF.

### 2. Roboto
- **Función:** Alternativa robusta si se busca un look más corporativo/Android-native.
- **Justificación:** Ubicua, muy legible, pero ligeramente más burocrática.

### 3. System Font Stack (Alternativa sin descargas)
- **Función:** Font UI por defecto (San Francisco / Segoe UI).
- **Justificación:** Cero impacto en performance. No requiere descarga.

## Familias Semánticas
- **Display Font:** Inter (Pesos 700, 800) para hero headers y números grandes.
- **Heading Font:** Inter (Pesos 600, 700) para títulos institucionales.
- **Body Font:** Inter (Peso 400, 500) para lectura.
- **UI Font:** Inter (Peso 500) para botones y navegación.
- **Monospace Font:** JetBrains Mono o SF Mono para logs/código (si aplica en soporte técnico).

*(Nota: typography.ts permanece inalterado hasta la aprobación de estas candidatas)*.
