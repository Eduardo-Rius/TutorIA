# Iconography (CANDIDATE)

El sistema de iconografía complementa la tipografía y guía al usuario por la interfaz.

## Atributos Visuales
- **Estilo de línea:** Stroke (Línea) para íconos UI estándar; Fill (Sólido) para íconos activos/seleccionados.
- **Grosor (Stroke Width):** 2px (base 24px) para asegurar legibilidad en monitores de baja resolución.
- **Esquinas (Corners):** Rounded (amigable, alineado con el robot y la pedagogía).
- **Tamaño Base:** 24x24px para hit targets accesibles; 16x16px para data tables o tags.
- **Grid:** 24px con 2px de padding interno.

## Colores Semánticos
- **Default:** `textSecondary` (Gris azulado).
- **Hover/Active:** `brandTeal` o `brandNavy`.
- **Feedback:** `success` (Verde), `danger` (Rojo), `warning` (Naranja).

## Íconos del Master Logo (Evaluación)
Los seis íconos promocionales que acompañan al logo maestro (Planeaciones pedagógicas, Normatividad IMSS, Tutoriales, Consulta, Aprende a tu ritmo, Multiplataforma) son de estilo **Dual Tone / Illustrative**.
- **Decisión:** Estos íconos promocionales son válidos como elementos decorativos (features) en Landing Pages o Dashboards de bienvenida.
- **Restricción:** NO deben ser copiados automáticamente a la interfaz funcional (Data tables, botones de acción). La interfaz funcional requiere íconos monocromáticos estrictos (ej. Lucide, Heroicons, Phosphor) para evitar fatiga visual.
