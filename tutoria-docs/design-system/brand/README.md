# Brand Architecture

Este directorio contiene la identidad oficial y maestra de TutorIA.

## Directorios
- `logos/`: Logos maestros, imagotipos, logotipos e isotipos en todas sus variantes.
- `colors/`: Paleta institucional oficial.
- `typography/`: Fuentes y estilos institucionales.
- `icons/`, `illustrations/`: Gráficos de soporte.
- `documents/`, `presentations/`: Identidad para documentos PDF y Keynote/PPT.
- `marketing/`, `social/`: Identidad para canales de adquisición.

Por favor consultar `Brand_Registry.md` para el registro oficial de activos.
