### Identificación

Producto: TutorIA Platform
Versión: 0.9.0
Fecha: 23 de julio de 2026
Estado: Arquitectura base estable

### Objetivo de la versión

Establecer una base técnica limpia, segura y reutilizable para construir la versión productiva de TutorIA.

### Alcance incluido

* Infraestructura React.
* Autenticación.
* Manejo de sesión.
* Rutas protegidas.
* Firebase.
* n8n.
* Estructura de proyecto.
* Documentación base.
* Control de versiones.

### Alcance excluido

* Planeación Semanal.
* IA pedagógica final.
* Flujo de aprobación.
* PDF institucional final.
* Chat normativo.
* Dashboard operativo.
* Reportes del piloto.

### Criterio de salida

La versión podrá considerarse aprobada cuando:

* compile sin errores;
* no contenga credenciales;
* arranque desde OneDrive;
* Git funcione correctamente;
* el repositorio quede preparado para el Sprint 1.
